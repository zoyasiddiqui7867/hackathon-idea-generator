# 🚀 Hackathon Idea Generator

A simple and powerful tool that helps developers generate innovative and practical hackathon project ideas instantly. Whether you're a beginner or an experienced developer, this tool helps you overcome "what to build?" and jump straight into creating. 


Live Project
👉 https://hackathon-idea-finder.vercel.app/
---

## ✨ Features

- 🎯 Generates unique hackathon project ideas  
- ⚡ Quick and easy to use  
- 💡 Covers multiple domains (AI, Web, Apps, etc.)  
- 🧠 Helps improve creativity and ideation  
- 🚀 Great starting point for real-world projects  

---

## 🛠️ Tech Stack

- React  
- Vite  
- Tailwind CSS  
- JavaScript  

---

## ⚙️ Development Setup

This project is built using **React + Vite + Tailwind CSS**, providing a fast and modern development experience with Hot Module Replacement (HMR) and utility-first styling.

### Plugins Used:
- @vitejs/plugin-react (Babel-based Fast Refresh)
- @vitejs/plugin-react-swc (SWC-based Fast Refresh)

---

## 📌 How to Use

1. Clone the repository  
   ```bash
   git clone https://github.com/zoyasiddiqui7867/hackathon-idea-generator.git
2. Navigate to the project folder:  cd hackathon-idea-generator
4. Install dependencies :npm install
5. Run the development server:npm run dev
6. Open in browser and start generating ideas 🎉

Why I Built This?

During hackathons, I often struggled with coming up with unique and practical ideas. So I built this tool to help developers quickly generate ideas and focus more on building rather than overthinking.
